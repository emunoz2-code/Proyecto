# Proyecto de vehículo móvil con ESP32

- [Parcial 2 · Firmware en MicroPython](firmware/): control del vehículo y montaje en [Wokwi](https://wokwi.com/projects/479614304886635521).
- [Parcial 3 · Interfaz en Python](interfaz/): aplicación de escritorio con joystick, gráficas y simulación de bomberos.

Para ejecutar la interfaz desde la raíz del repositorio:

```bash
cd interfaz
python -m pip install -r requirements.txt
python main.py
```
